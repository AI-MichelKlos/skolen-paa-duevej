# Skolen på Duevej

En hyggelig 3D-gåtur i tegnefilmsstil rundt på Skolen på Duevej på Frederiksberg.

**Spil her:** https://ai-michelklos.github.io/skolen-paa-duevej/

Gå rundt mellem de røde murstenshuse, de gule huse og den nye træbygning. Tolv duer er landet rundt omkring på skolen, og de flyver op, når man kommer tæt på. Kan du finde dem alle?

## Styring

| Computer | Telefon og tablet |
| --- | --- |
| W A S D eller piletaster: gå | Venstre tommel: gå |
| Shift: løb | Højre tommel: kig rundt |
| Mellemrum: hop | Hop-knappen: hop |
| Træk med musen: kig rundt, rul for at zoome | |
| N: dag eller aften · M: vis eller skjul kortet | |

## Om spillet

- Én HTML-fil med [three.js](https://threejs.org/) (hentes fra jsDelivr). Ingen billeder eller andre filer.
- Bygningerne er tegnet frit efter fotos og et luftfoto af skolen. Placeringer og detaljer er forenklede.
- Fundne duer, dag/aften og lyd huskes i browseren.
